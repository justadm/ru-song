# ru-song

Три самостоятельных навыка для работы с русскими стихотворениями и песнями. Авторский навык помогает создать и доработать текст; редакторский оценивает готовый вариант и предлагает обоснованные точечные правки; продюсерский ищет музыкальный характер и выстраивает аранжировку.

| Навык | Задача |
| --- | --- |
| [ru-song-writing](skills/ru-song-writing/SKILL.md) | Создание и совместная доработка стихов и песен: образы, характер, развитие чувства и речевая интонация; обычный пакет Suno при отдельной установке |
| [ru-song-editor](skills/ru-song-editor/SKILL.md) | Независимое ревью текста, техническая и художественная оценка, сравнение выигрыша и возможных потерь от правок |
| [ru-song-producer](skills/ru-song-producer/SKILL.md) | Креативное продюсирование, разные музыкальные трактовки, аранжировка, вокал, Styles для Suno и работа с дублями |

Навыки сохраняют авторский голос и различают художественный выбор и ошибку. Уместные повторы и неточные рифмы допустимы. По одному тексту оценка певучести предварительная: проверка звучания требует мелодии или записи. Разбор и предложение вариантов сами по себе не разрешают менять файлы.

Авторский навык развивает индивидуальность текста через связанные детали, поступки и реакции героя, движение чувства и речевую интонацию. Редактор объясняет, что работает в исходнике и что меняется при замене; более гладкий вариант не считается автоматически лучшим. Простоту, спокойствие и обобщение в припеве сохраняют, когда они служат песне. Узкая техническая проверка не расширяется до художественной переработки.

Продюсер ищет слышимую особенность песни и связывает её со смыслом. Разные трактовки могут отличаться грувом, фразировкой, гармонией, поведением инструментов и развитием; необычность не является обязательной целью. Для работы со Styles есть [справочник по официальным рекомендациям Suno](skills/ru-song-producer/references/suno-style.md) с датой проверки и оригинальными примерами. Подбор звучания не означает переписывания согласованных слов.

## Состав

```text
skills/
  ru-song-writing/
    SKILL.md
    agents/openai.yaml
    references/russian-verse.md
  ru-song-editor/
    SKILL.md
    agents/openai.yaml
  ru-song-producer/
    SKILL.md
    agents/openai.yaml
    references/suno-style.md
```

Памятка по русскому стиху загружается авторским навыком для технических задач. Редактор содержит собственное короткое правило строгого разбора и не зависит от установки авторского навыка. Продюсер загружает справочник Suno при подготовке Styles. Навыки можно использовать вместе или по отдельности.

## Установка в проект

Сначала скачайте репозиторий из корня своей мастерской:

```bash
git clone https://github.com/justadm/ru-song.git ru-song
```

Затем выберите каталог своего инструмента. Ниже команды для первой установки всех трёх навыков.

### Codex

Проектные навыки размещаются в `.agents/skills/`. [Официальная документация Codex](https://developers.openai.com/codex/skills).

```bash
mkdir -p .agents/skills
test ! -e .agents/skills/ru-song-writing && \
test ! -e .agents/skills/ru-song-editor && \
test ! -e .agents/skills/ru-song-producer && \
cp -R ru-song/skills/ru-song-writing ru-song/skills/ru-song-editor ru-song/skills/ru-song-producer .agents/skills/
```

### Claude Code

Проектные навыки размещаются в `.claude/skills/`. [Официальная документация Claude Code](https://code.claude.com/docs/en/skills).

```bash
mkdir -p .claude/skills
test ! -e .claude/skills/ru-song-writing && \
test ! -e .claude/skills/ru-song-editor && \
test ! -e .claude/skills/ru-song-producer && \
cp -R ru-song/skills/ru-song-writing ru-song/skills/ru-song-editor ru-song/skills/ru-song-producer .claude/skills/
```

Проверки существования каталогов защищают установленную версию от случайной перезаписи. Для установки только одного навыка скопируйте соответствующий каталог из `skills/` в каталог навыков своего инструмента, предварительно проверив, что целевой каталог свободен.

Если авторский и редакторский навыки уже установлены, сначала обновите скачанный репозиторий до версии, содержащей `ru-song-producer`. Для чистого клона на `main` после слияния PR №2 выполните:

```bash
git -C ru-song pull --ff-only
```

При собственных изменениях или другой рабочей ветке используйте отдельный свежий клон в свободном каталоге, сохранив прежний. Если назовёте его `ru-song-fresh`, в команде копирования ниже замените источник `ru-song/skills/ru-song-producer` на `ru-song-fresh/skills/ru-song-producer`. Продюсер будет доступен в свежем клоне `main` после слияния PR №2.

Затем добавьте только продюсерский навык:

```bash
test ! -e .agents/skills/ru-song-producer && \
cp -R ru-song/skills/ru-song-producer .agents/skills/
```

Для Claude Code замените `.agents/skills/` на `.claude/skills/` в обеих строках.

### Другие агенты

Для агента с поддержкой формата `SKILL.md` используйте его документированный каталог навыков. Копируйте каталог выбранного навыка целиком, включая `references/`, если он есть. Путь установки и способ явного вызова определяются конкретным инструментом.

При совместной установке в правилах проекта (`AGENTS.md` для Codex, `CLAUDE.md` для Claude Code) можно закрепить роли: создание и совместная доработка слов через `ru-song-writing`; независимое ревью и строгий технический разбор через `ru-song-editor`; выбор звучания, аранжировка, музыкальные пометки и Styles через `ru-song-producer`. В полном пакете авторский навык отвечает за слова, продюсерский — за музыкальное решение. Явный выбор пользователя имеет приоритет. При отдельной установке авторский навык также умеет подготовить обычное описание звучания. Правила хранения текстов и версий задаёт сама мастерская.

## Примеры запросов

В Codex используйте `$ru-song-writing`, `$ru-song-editor` и `$ru-song-producer`, как в примерах ниже. В Claude Code начинайте запрос с `/ru-song-writing`, `/ru-song-editor` или `/ru-song-producer`; остальной текст запроса можно сохранить.

Создание:

```text
Используй $ru-song-writing. Напиши спокойную песню о возвращении домой.
Начни с текста; промпт звучания подготовим после согласования.
```

Ревью:

```text
Используй $ru-song-editor. Независимо разбери этот текст:
смысл, рифмы, ритм и припев. Предложи точечные правки.
Пока ничего не меняй в файлах.
```

Строгий размер:

```text
Используй $ru-song-editor. Проверь пятистопный ямб:
покажи естественные ударения и метрическую схему каждой строки,
различи допустимые вариации, спорные чтения и нарушения формы.
```

Можно передать текст в сообщении или указать доступный локальный файл. Название редакторского навыка обозначает роль ревью; оно само по себе не создаёт отдельного агента или независимого исполнителя.

Поиск звучания:

```text
Используй $ru-song-producer. Предложи несколько музыкальных трактовок
этой песни: сохрани тепло и юмор, но найди разные грувы и приёмы
аранжировки. Объясни, чем они будут отличаться на слух.
Согласованный текст не меняй.
```

Готовый стиль:

```text
Используй $ru-song-producer. Для выбранного акустического свинга
подготовь Styles для Suno и музыкальные пометки к тексту.
Сохрани слова; дай копируемые блоки отдельно.
```

## Границы

В репозитории только инструкции навыков, UI-описания и справочные материалы. Личные тексты песен, аудиозаписи и содержимое мастерской в пакет не включены; промпты в справочнике продюсера служат оригинальными иллюстрациями. Навыки не управляют аккаунтом Suno, не расходуют кредиты и не публикуют песни.
