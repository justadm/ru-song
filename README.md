# ru-song

Два самостоятельных навыка для работы с русскими стихотворениями и песенными текстами. Авторский навык помогает создать и доработать текст; редакторский оценивает готовый вариант и предлагает обоснованные точечные правки.

| Навык | Задача |
| --- | --- |
| [ru-song-writing](skills/ru-song-writing/SKILL.md) | Создание стихов и песен, совместная авторская доработка, подготовка описания звучания для Suno |
| [ru-song-editor](skills/ru-song-editor/SKILL.md) | Независимое ревью существующего текста, сравнение вариантов, проверка строгого размера и оценка правок |

Оба навыка сохраняют авторский голос, различают художественный выбор и ошибку, допускают уместные повторы и неточные рифмы. По одному тексту оценка певучести предварительная: проверка звучания требует мелодии или записи. Разбор и предложение вариантов сами по себе не разрешают менять файлы.

## Состав

```text
skills/
  ru-song-writing/
    SKILL.md
    agents/openai.yaml
    references/russian-verse.md
  ru-song-editor/
    SKILL.md
    agents/openai.yaml
```

Памятка по русскому стиху загружается авторским навыком для технических задач. Редактор содержит собственное короткое правило строгого разбора и не зависит от установки авторского навыка. Навыки можно использовать вместе или по отдельности.

## Установка в проект

Сначала скачайте репозиторий из корня своей мастерской:

```bash
git clone https://github.com/justadm/ru-song.git ru-song
```

Затем выберите каталог своего инструмента. Ниже команды для первой установки обоих навыков.

### Codex

Проектные навыки размещаются в `.agents/skills/`. [Официальная документация Codex](https://developers.openai.com/codex/skills).

```bash
mkdir -p .agents/skills
test ! -e .agents/skills/ru-song-writing && \
test ! -e .agents/skills/ru-song-editor && \
cp -R ru-song/skills/ru-song-writing ru-song/skills/ru-song-editor .agents/skills/
```

### Claude Code

Проектные навыки размещаются в `.claude/skills/`. [Официальная документация Claude Code](https://code.claude.com/docs/en/skills).

```bash
mkdir -p .claude/skills
test ! -e .claude/skills/ru-song-writing && \
test ! -e .claude/skills/ru-song-editor && \
cp -R ru-song/skills/ru-song-writing ru-song/skills/ru-song-editor .claude/skills/
```

Проверки существования каталогов защищают установленную версию от случайной перезаписи. Для установки только одного навыка скопируйте соответствующий каталог из `skills/` в каталог навыков своего инструмента, предварительно проверив, что целевой каталог свободен.

### Другие агенты

Для агента с поддержкой формата `SKILL.md` используйте его документированный каталог навыков. Копируйте каталог выбранного навыка целиком, включая `references/`, если он есть. Путь установки и способ явного вызова определяются конкретным инструментом.

В правилах проекта (`AGENTS.md` для Codex, `CLAUDE.md` для Claude Code) можно закрепить роли: создание, совместная доработка и промпты через `ru-song-writing`; независимое ревью и строгий технический разбор через `ru-song-editor`. Правила хранения текстов и версий задаёт сама мастерская.

## Примеры запросов

В Codex используйте `$ru-song-writing` и `$ru-song-editor`, как в примерах ниже. В Claude Code начинайте запрос с `/ru-song-writing` или `/ru-song-editor`; остальной текст запроса можно сохранить.

Создание:

```text
Используй $ru-song-writing. Напиши спокойную песню о возвращении домой.
Начни с текста; промпт звучания подготовим после согласования.
```

Ревью:

```text
Используй $ru-song-editor. Независимо разбери этот текст:
смысл, рифмы, ритм и припев. Предложи точечные правки.
Пока ничего не меняй в файлах.
```

Строгий размер:

```text
Используй $ru-song-editor. Проверь пятистопный ямб:
покажи естественные ударения и метрическую схему каждой строки,
различи допустимые вариации, спорные чтения и нарушения формы.
```

Можно передать текст в сообщении или указать доступный локальный файл. Название редакторского навыка обозначает роль ревью; оно само по себе не создаёт отдельного агента или независимого исполнителя.

## Границы

В репозитории только инструкции навыков, UI-описания и памятка. Тексты песен, аудиозаписи и содержимое личной мастерской в пакет не включены. Навыки не управляют аккаунтом Suno, не расходуют кредиты и не публикуют песни.
